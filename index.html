PDF 번역기

PDF를 올리고, 언어를 고르고, 원본 양식 그대로 번역된 PDF를 저장하세요. 모든 처리는 브라우저에서 이루어집니다.

1PDF 파일 업로드
여기로 PDF를 끌어다 놓거나 클릭해서 선택하세요 (최대 10개까지 한 번에)
    2번역할 언어 선택
    API 키는 이 브라우저에서 Anthropic으로 직접 전송되며 어디에도 저장되지 않습니다.
    Chrome에 들어 있는 번역 기능을 사용합니다. 처음 쓰는 언어는 언어 팩을 한 번 내려받고, 그 뒤로는 인터넷 없이도 번역됩니다.
    3번역본 확인 및 PDF 저장
    번역문을 클릭하면 직접 수정할 수 있습니다. 마우스를 올리면 원문이 보입니다. 수정한 내용도 PDF에 반영됩니다.
